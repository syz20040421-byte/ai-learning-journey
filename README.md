# AI_KnowledgeBase
## 仓库介绍
- 本仓库主要用于个人的AI开发知识学习，记录13周的求职学习计划
## 仓库目录
1. daily
- 主要用于存储AI每天发布的学习任务
2. notes
- 主要用于存储每天的学习笔记以及问题回答的文件
3. review
- 主要用于存储AI对每天完成任务的检查报告
4. submissions
- 主要用于存储每天的代码任务
### 怎么跑今天的 practice 示例

```bash
".venv/Scripts/python.exe" submissions/2026-08/2026-W34/2026-08-20/pydantic_practice.py
```
