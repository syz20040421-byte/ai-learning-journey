1. 词汇：format 格式, variable 变量, method 方法, argument 参数, encoding 编码, serialization 序列化, template 模板, debugging 调试, representation 表示, structure 结构, syntax 语法, parameter 参数, expression 表达式, execution 执行, iteration 迭代

2. 摘抄
- 原文：If you have a really long format string that you don’t want to split up, it would be nice if you could reference the variables to be formatted by name instead of by position.
- 译文：如果你有一个很长的格式字符串，不想把它拆开，那么如果你能通过名字而不是位置来引用要格式化的变量，那就好了。

3. 心得
- 程序输出的几种方式：最简单的是 `print()`，适合快速显示内容；如果想更精确地控制输出格式，可以使用 `f-string`、`str.format()` 或旧式的 `% `格式化。`f-string` 最直观，能直接把变量或表达式嵌入字符串中；`str.format()` 更灵活，适合按位置或按名称填充内容；而手动拼接、切片和对齐方法则能让输出更精细。
- 文件读写的基本方法：`open()` 用来打开文件，常见模式有 `r、w、a、r+，`还可以通过 `b` 进入二进制模式。文本模式适合处理字符串，会自动处理换行符和编码；二进制模式则适合图片、可执行文件等字节数据。使用 `with open(...) as f: `是推荐写法，因为它能在代码块结束后自动关闭文件，避免资源泄漏。文件对象常用方法包括 `read()、readline()、write()、seek() 和 tell()，`分别用于读取、写入和控制文件位置。
- `JSON`数据保存与恢复。当数据结构比较复杂，比如列表嵌套字典时，手工解析会很麻烦，所以 `Python` 提供了 `json` 模块来进行 序列化 和 反序列化。`json.dumps()` 可以把 `Python` 对象转换成 `JSON` 字符串，`json.dump()` 可以直接写入文件，`json.load()` 则可以从文件中读回对象。`JSON` 适合数据交换和跨语言通信，但要注意文件通常应使用 `UTF-8` 编码。这部分的核心思想是：用标准格式保存结构化数据，比手动处理更安全、更方便。

# 今日一问
1. `with open(...) as f:` 里，`with` 到底做了什么让文件「自动关闭」？如果 `with` 块里抛了异常，文件还会关吗？
- `with open(...) as f:` ：进入with代码块后会调用`__enter__()` 和 `__exit__()`两个方法，进入时会调用`__enter__()`进行文件读取，退出with代码块时会调用`__exit__()`方法关闭文件。会，不管`with`块里发生什么，最后一定会关闭文件，释放系统资源是`with`最主要的任务
