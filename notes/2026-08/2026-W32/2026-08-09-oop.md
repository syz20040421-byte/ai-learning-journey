# 技术英语
1. 词汇：constructor 构造函数、inheritance 继承、encapsulation 封装、polymorphism 多态、instance 实例、interface 接口、property 特性/属性、class variable 类变量、instance variable 实例变量、abstraction 抽象、module 模块、instance 实例、attribute 属性、method 方法、object-oriented 面向对象的

2. 摘抄
    原文：It is important to realize that scopes are determined textually: the global scope of a function defined in a module is that module’s namespace, no matter from where or by what alias the function is called. On the other hand, the actual search for names is done dynamically, at run time – however, the language definition is evolving towards static name resolution, at “compile” time, so don’t rely on dynamic name resolution!
    译文：必须认识到，作用域是由源代码文本位置决定的：一个在模块中定义的函数，其全局作用域就是该模块的命名空间，无论这个函数是从哪里、或者通过什么别名被调用的。另一方面，对名称的实际查找是在运行时动态进行的——然而，Python 的语言定义正朝着在‘编译’时进行静态名称解析的方向演进，所以不要依赖动态名称解析！

3. 心得
- 类是创建对象的蓝图：类把数据和功能绑定在一起，定义新类会创建新类型，支持实例化生成对象；对象通过属性维持状态，通过方法修改状态，并支持继承、多态等OOP标准特性。
- 命名空间与作用域决定名称查找顺序：名称到对象的映射存储在命名空间中，属性查找时遵循从局部、闭包、全局到内置的四层嵌套作用域规则；global和nonlocal语句可显式控制变量在不同作用域中的重新绑定。
- 实例方法与属性遵循“实例优先”及自动传参机制：调用实例方法时，实例对象会自动作为第一个参数（通常命名为self）传入对应函数；当实例属性和类属性同名时，属性查找优先选择实例属性，而类变量则为所有实例所共享。

# 笔记
1. 类属性 `school` 和实例属性 `name` 在**内存里**分别存在哪里？为什么 `stu1.school = "X"` 只影响 stu1，而 `Student.school = "X"` 影响所有人？（提示：类属性和实例属性分别在哪个「名字空间」里查找）
- 类属性 `school`存放在类Student下，实例属性 `name`存放在实例下
- `stu1.school = "X"`属于只改变stu1的school属性，不改变全局school属性，`Student.school = "X"`改变了全局的school属性
2. `def __init__(self, scores=[])` 为什么错？画/写一下：这个默认列表在内存里是「一份」还是「每实例一份」？两个学生各 add_score 后会发生什么？
- `def __init__(self, scores=[])` 列表属于可变对象，运行后会建立一个空列表绑定到scores上，后面不管建多少个实例，他们的scores都会指向这个列表
- 一份
- 这两个学生再调用scores时会同时指向这个列表
