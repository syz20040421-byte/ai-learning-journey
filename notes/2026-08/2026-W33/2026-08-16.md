# 学习笔记
1. 装饰器的核心思想是用函数包装函数，在不改变原函数的情况下，为函数增加功能或用法。主要用途就是将经常复用的功能写在装饰器中可以方便调用。
2. 其中slow_add(a,b)是原函数，timer(func)是装饰器函数，func指代的就是传入的原函数，而wrapper(*args, **kwargs)是包装函数，
  *args, **kwargs指代原函数中传入的一切参数，当原函数中有传参是必须要有(*args, **kwargs)。包装函数中会给原函数添加新的功能，并调用原函数。末尾必须return result，不然调用原函数返回的结果就是None。@timer的写法等价于 slow_add = timer(slow_add)
```python
  import time
  def timer(func):
      def wrapper(*args, **kwargs):
          t0 = time.time()
          result = func(*args, **kwargs)   # 调用原函数
          print(f"{func.__name__} 耗时 {time.time()-t0:.4f}s")
          return result                     # 把原函数的结果原样返回
      return wrapper                        # 返回包装函数

  @timer
  def slow_add(a, b):
      time.sleep(0.1)
      return a + b

  print(slow_add(1, 2))   # slow_add 耗时 0.1000s / 3
  ```

3. 当装饰器有传参时（如 @repeat(3)），装饰函数要采用三层嵌套，第一层用于传参，第二层用于传入原函数，第三层作为包装函数
```python
def repeat(num_times):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(num_times):
                func(*args, **kwargs)
        return wrapper
    return decorator

@repeat(3)
def say_hello():
    print("Hello!")

say_hello()
```
4. 和类有关的装饰器分为两种：给类写装饰器和用类写装饰器
5. 迭代器本质上是带状态指针的惰性数据流，通过 __next__ 按需取值并在耗尽时抛出 StopIteration 来终止，具有极致的内存优势（如逐行读大文件），但只能单向一次性前进，无法重置；for 循环底层正是依赖反复调用 next 并捕获该异常来结束遍历。
