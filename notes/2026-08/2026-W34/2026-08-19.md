# 学习笔记
1. 模块与`import`：一个.py文件就是一个模块，不同模块可以通过`import`导入其他模块的功能
2. 包与`_init_.py`：包是由多个模块组成的文件夹，其中`_init_.py`常用作其他模块的导入接口，可以通过`_init_.py`直接在包根目录下调用相应模块而不用填完整的模块路径
3. `logging（日志）`：本身是一个日志库，用来产生日志。其中输出级别由低到高是：`DEBUG < INFO < WARNING < ERROR`。写法如下：
  ```python
  import logging  #导入库
  # level=logging.INFO 设定输出级别>=INFO，asctime指生成的时间戳，levelname指日志等级，message是日志内容
  # logging.basicConfig() 只在主模块配置一次
  logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")
  logging.info("记录: 模块与包 120 分钟")
  # 输出: 2026-08-19 10:30:00,123 INFO 记录: 模块与包 120 分钟
  ```
4. python->json：
- 文件转：json.dump(转换的内容,file) 
- 字符串转：json.dumps(转换的内容)
json->python:
- 文件转：json.load(file)
- 字符串转：json.loads(str)
无s是文件，有s是字符串
5. datetime
- date：年月日（2026-08-20）
- time：时分秒（21:20:21）
- datetime：date + time
- timedelta：时间差 n = now -(+) timedelta(day=3) 现在到3天前（后）（week：周，hours：小时）
- tzinfo：时区信息
6. 字符串->时间：datetime.strptime()；时间->字符串：datetime.strftime()
7. `Path(path).exists()`可以判断文档是否存在
8. `f.read()`之后再调用`json.loads()`读取到的文档是空的，会报错
