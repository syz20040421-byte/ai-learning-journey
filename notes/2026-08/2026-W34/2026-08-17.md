@dataclass
1. 导入：from dataclass import dataclass
2. 功能：生成`__init__,__repr__,__eq__`的样板代码
3. `__init__ `：初始化 self.x = x
4. `__repr`：将实例属性以字符串的形式打印
5. `__eq__`：用`==`判断两个实例对象的属性是否相等，由此来判断是否重复
6. `field()`：针对可变默认值，（当实例属性为可变值时（如字典和列表），所有实例共享同一实例属性）
    用法：
```python
  from dataclasses import dataclass, field

  @dataclass
  class Student:
      name: str
      scores: list = field(default_factory=list)   # 每次实例化新列表

  a = Student("张三"); a.scores.append(90)
  b = Student("李四")
  print(b.scores)   # [] —— 李四的列表是全新的，看不到张三的 90
```
7. `frozen=True`：实例创建后实例属性不可更改（只读）
8. `dataclass->dict`：实例转字典，`b_dict = asdict(b)`，b为实例对象
    `dict->dataclass`：字典转实例，`b = Student(**b_dict)`
    `dataclass->json`：实例转json文件，`b_json = json.dumps(asdict(b), ensure_ascii=False)`
    `json->dataclass`：json转实例，`b = json.loads(b_json)`，在手动插入
    - 示例：
```python
  #dataclass<->dict
  from dataclasses import asdict

  s = Student("张三", [90, 85])
  d = asdict(s)          # {'name': '张三', 'scores': [90, 85]}
  print(d["name"])       # 当 dict 用
  s2 = Student(**d)      # 关键字展开，转回 Student
  print(s2 == s)         # True

  #dataclass<->json 
  user_json = json.dumps(asdict(user), ensure_ascii=False)
  print(user_json)

  json_str = '{"name": "王五", "age": 28, "address": {"city": "上海", "street": "南京路"}}'
  data = json.loads(json_str)

  # 步骤2: 字典转成数据类（需手动处理嵌套）
  # 简易方式（仅适用于嵌套层级少的情况）：
  user = User(
      name=data["name"], 
      age=data["age"],
      address=Address(**data["address"])  # 手动解包嵌套字典
  ) 

  #采用dataclass_json库
  from dataclasses import dataclass
  from dataclass_json import dataclass_json

  @dataclass_json
  @dataclass
  class Address:
      city: str
      street: str

  @dataclass_json
  @dataclass
  class User:
      name: str
      age: int
      address: Address

  user = User("赵六", 35, Address("广州", "天河路"))

  # 一键转 JSON 字符串
  json_str = user.to_json() 
  print(json_str) # {"name": "赵六", "age": 35, "address": {"city": "广州", "street": "天河路"}}

  # 一键从 JSON 字符串恢复对象
  new_user = User.from_json(json_str)
  print(new_user.address.city) # 广州
```

2. **（今日机制）** `@dataclass` 类里你没写 `__init__`，`Student("张三")` 却能创建对象——`__init__` 是谁写的？如果字段写成 `scores: list = []` 会出什么问题（回忆 Day 4 可变默认参数）？为什么 `field(default_factory=list)` 能解决？
- 是装饰器`@dataclass`已经生成好的
- 所有实例对象会共享这一个实例属性，如果前后输入张飞和李明的成绩，在调用某一人成绩的时候会显示出两个人的成绩
- `field(default_factory=list)`会在每一次创建实例对象的时候重建成绩列表，使得所有人的成绩互不干扰
3. **（场景题）** API 返回给你 `{"name": "李四", "scores": [88, 92]}`，用 dict 访问 `d["name"]` 也能拿到数据——那为什么还要转成 `Student`？什么时候必须转、什么时候用 dict 就行？（提示：想想第 4 周你要把 LLM 输出的 JSON 变成程序里能校验的对象）
- 转成实例对象方便统一数据进行管理，以及数据校验，当脏数据转成实例对象时会第一时间发出警告，同时也方便后续数据的调用和维护
- dict场景：临时数据或者数据没有什么可用性和后续维护的需要
- 转实例场景：数据需要长期或者多人协作使用，需要对数据进行筛选或者维护时
