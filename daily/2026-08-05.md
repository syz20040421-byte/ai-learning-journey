昨天 `first_unique` 里 `items.count(s)` 在循环内调用，是 O(n²)——数据一上万就卡死。今天学会用 dict 计数把它改写成 O(n)，并掌握 dict / set 的选型判断。**这是面试第一个必考题**（「这段代码复杂度多少？怎么优化？」），也是后面所有数据处理的地基。

## 今日知识点预习 (10-15 min)

动手前先过一遍，有概念再写代码：

1. dict：键值对存储，`d[key]` 取值、`key in d` 判断存在、`.get(key, 默认值)`
2. **dict 查找是 O(1)**，list 查找是 O(n)——为什么？（哈希）
3. set：只存不重复的元素，`x in s` 判断成员、`&` 交集、`|` 并集
4. 大 O 记号：O(1) 常数时间 / O(n) 线性 / O(n²) 平方——只看数据量变大时增长趋势
5. 为什么循环里调 `list.count()` 是 O(n²)：外层 n 次 × 每次 count 扫一遍 n
6. 比较 `None` 用 `is None`，不用 `== None`
7. dict 推导式：`{k: v for ...}`（可选，查得到就行）
