## 今日知识点预习 (15-20 min · 详读)

### 1. BaseModel：类声明 = 校验规则

- **是什么**：`from pydantic import BaseModel`；`class Student(BaseModel): name: str; age: int`——字段的类型注解就是校验规则。
- **为什么今天用**：Day 11 你亲手试过 dataclass 的注解只是「装饰」，传错类型照样构造成功；Pydantic 在**创建实例时**自动校验，规则和数据结构写在一起。
- **怎么用**：
  ```python
  s = Student(name="张三", age=20)   # 正常
  Student(name=123, age=20)          # name 不是 str → 抛 ValidationError
  ```
- **坑**：校验发生在 `__init__` 时——「构造即校验」，不是用到才校验；不写 `try/except`，坏数据一进门程序就崩，这正是它和手写 `if` 校验的本质区别（错误集中在一个出口，而不是散落各处）。

### 2. 类型转换（宽松模式）

- **是什么**：Pydantic 默认**宽松**：`age: int` 收到字符串 `"21"` 会静默转成整数 21。
- **为什么今天用**：真实数据来自 JSON/CSV/网页表单，全是字符串；你手动 `int()` 会漏，Pydantic 顺手帮你转了。
- **怎么用**：`Student(name="李四", age="21")` → `s.age == 21` 且 `isinstance(s.age, int)` 为 True。
- **坑**：转不了才报错（`age="abc"` → ValidationError）；**布尔是 int 的子类**——`age=True` 会被转成 1，这是经典面试坑；字符串 `"021"` 转成 21 会丢前导零（如果 age 是学号/ID 就出事了，三问第 2 题考这个）。

### 3. Field 约束：范围/长度

- **是什么**：`from pydantic import Field`；`score: float = Field(ge=0, le=100)`——`ge` = 大于等于，`le` = 小于等于。
- **为什么今天用**：分数 150、年龄 -5 这种「类型对但值错」的数据，类型注解拦不住，必须加约束。这是 dataclass 做不到、Pydantic 白送的。
- **怎么用**：约束直接写在字段声明处：`score: float = Field(ge=0, le=100)`。
- **坑**：约束失败同样是 ValidationError，报错信息里能看到 `greater_than_or_equal_to` 字样；带默认值的写法是 `Field(default=0, ge=0)`（今天用不到默认值，知道有）。

### 4. ValidationError 结构

- **是什么**：校验失败抛的异常；`e.errors()` 返回**列表**，每条含 `loc`（哪个字段，可能是元组）、`msg`（人话描述）、`type`（错误类别）。
- **为什么今天用**：第 3 周 FastAPI 会把 ValidationError 自动转成 422 响应返回给前端——现在看懂结构，下周调接口报错不用查文档。
- **怎么用**：
  ```python
  except ValidationError as e:
      first = e.errors()[0]
      print(first["loc"], first["msg"])   # ('age',)  Input should be a valid integer
  ```
- **坑**：`ValidationError` 从 `pydantic` 顶层导入（不是 `pydantic.v1`）；一次校验会把**所有**错误一起收集进列表，不是只报第一条——`e.errors()` 长度就是错了几处。

### 5. 嵌套模型 + List[Model]

- **是什么**：模型的字段可以是另一个模型或模型列表：`class ClassRoom(BaseModel): students: list[Student]`。
- **为什么今天用**：真实数据（班级、订单、对话历史）都是嵌套结构；今天的成绩单就是「一堆学生」，逐条手动转太蠢。
- **怎么用**：`ClassRoom(students=[{"name": "张三", "age": 20, "score": 88.5}])`——传入 dict 列表，Pydantic 自动逐条转成 Student 实例。
- **坑**：嵌套校验是**递归**的——里面任何一条坏记录，整个 ClassRoom 构造失败；坏在第几条，错误信息 `loc` 会带下标，形如 `('students', 2, 'score')`（第 3 条记录的第 score 字段）。
