## 今日知识点预习 (15-20 min · 详读)

### 1. 模块与 import 机制

- **是什么**：一个 `.py` 文件就是一个模块。`import daylog.entries` 的意思是「找到这个文件、从头到尾执行一遍、把里面的名字挂到 `daylog.entries` 名下」。
- **为什么今天用**：今天要把 4 个文件互相引用。不懂 import 的查找规则，一拆文件就报 `ModuleNotFoundError`，而且不知道为什么。
- **怎么用**：
  ```python
  import daylog.entries            # 用 daylog.entries.add_entry 访问
  from daylog.entries import add_entry   # 直接用 add_entry
  from daylog import add_entry     # 包在 __init__.py 里帮你转发了（今天要写的）
  ```
- **坑**：`import` 会**执行整个文件**——所以文件顶层别放 print/副作用代码，调试输出要放 `if __name__ == "__main__":` 里（Day 4 学过）。模块只执行一次，重复 import 用的是缓存。

### 2. 包与 __init__.py

- **是什么**：**目录 + `__init__.py` = 包**。`__init__.py` 在包被 import 时执行一次，常用来「导出公共 API」。
- **为什么今天用**：daylog 的 4 个文件必须组成一个包，调用方才能写 `from daylog import add_entry` 而不是 `from daylog.entries import add_entry`——后者暴露内部结构，改文件名就崩。
- **怎么用**：
  ```python
  # daylog/__init__.py
  from .entries import add_entry   # 相对导入：点开头 = 当前包内
  ```
- **坑**：相对导入（`.` 开头）只能在包内用。**直接 `python main.py` 跑包里的文件会报 `ImportError: attempted relative import`**——必须从包外面用 `python -m daylog.main` 跑（这就是脚手架运行命令用 `-m` 的原因）。另外 `__init__.py` 可以是空文件，但今天要求你写导出。

### 3. logging：给程序装日志系统

- **是什么**：标准库 `logging` 按级别输出：`DEBUG < INFO < WARNING < ERROR`。`basicConfig` 一次配置，之后到处 `logging.info(...)`。
- **为什么今天用**：print 的输出没有级别、没有时间戳、上线后关不掉；logging 一条 `INFO` 记录自动带时间（预习 4 的 asctime），级别一调就能过滤。第 4 周 LLM 应用的每次 API 调用都要打日志，这是基本功。
- **怎么用**：
  ```python
  import logging
  logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")
  logging.info("记录: 模块与包 120 分钟")
  # 输出: 2026-08-19 10:30:00,123 INFO 记录: 模块与包 120 分钟
  ```
- **坑**：`level=logging.INFO` 不设的话默认 WARNING，`info` 全看不见（「日志不见了」先查这）。`%(asctime)s` 是 logging 自动填的时间戳，格式串里必须有它才打印时间。

### 4. json：程序间的普通话

- **是什么**：`json.dumps(对象)` 转字符串、`json.loads(字符串)` 转回；读写文件用 `json.dump` / `json.load`。Python 的 dict/list 和 JSON 一一对应。
- **为什么今天用**：学习日志要存成文件、下次跑再读回来——这就是最朴素的「持久化」。第 4 周 LLM 的结构化输出、第 5 周 RAG 的文档存储都是 JSON。
- **怎么用**：
  ```python
  with open("study_log.json", "w", encoding="utf-8") as f:
      json.dump(entries, f, ensure_ascii=False, indent=2)
  ```
- **坑**：`ensure_ascii=False` 忘写，中文全变 `\uXXXX`；`indent=2` 只是给人看的排版；**空文件 `json.load` 会抛 `JSONDecodeError`**——今天 load_entries 要处理「文件不存在」和「空文件」两种情况，别让它炸。

### 5. datetime：日期别手拼

- **是什么**：`datetime.date.today()` 拿今天，`.isoformat()` 转成 `"2026-08-19"` 这种标准字符串。
- **为什么今天用**：日志条目要记「今天」的日期。手写 `"2026-08-19"` 明天就错；`isoformat()` 是全世界通用的排序友好格式。
- **怎么用**：
  ```python
  from datetime import date
  today = date.today().isoformat()   # "2026-08-19"
  ```
- **坑**：`date.today()` 返回的是 date **对象**不是字符串，直接塞进 dict 再 json.dump 会 `TypeError: Object of type date is not JSON serializable`——必须 `.isoformat()` 转字符串。反过来字符串转日期用 `date.fromisoformat()`（今天用不到，知道有）。
