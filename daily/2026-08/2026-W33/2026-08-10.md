## 今日知识点预习 (10-15 min)

动手前先过一遍，有概念再写代码：

0. **运行环境（今天开始用 venv，重要）**：仓库已建好 `.venv`（uv 管理）并装好 requests。**你的 `python` 命令默认指向别处（hermes 环境，没有 requests），直接 `python 06_integration.py` 会报 ModuleNotFoundError**。两种跑法任选：
   - **推荐：先激活** `source .venv/Scripts/activate`（git-bash）或 `.venv\Scripts\activate`（cmd），之后 `python` 就是 .venv 的了，再 `python 06_integration.py`
   - 不激活就全路径：`.venv/Scripts/python.exe 06_integration.py`
   - 实测：`requests.get(open-meteo 北京) → 200, 27.0℃` 链路已通，requests 2.33.0

1. **requests 库**：`requests.get(url, timeout=10)` 发 GET 请求；`.status_code` 是 HTTP 状态码（200 = 成功）；`.json()` 把响应体解析成 Python 的 dict/list
2. **URL 查询参数**：`?latitude=39.9&longitude=116.4` 是问号后面的键值对，API 靠它收参数
3. **timeout 为什么必须设**：网络请求可能永远不返回（断网 / 服务器挂），不设 timeout 程序会无限卡住；文件读取出错会立刻抛异常，网络请求失败可能「沉默地等」——这是今天文件 IO 和网络 IO 最大的区别
4. **嵌套 dict 访问**：`d["current_weather"]["temperature"]` 一层层往下取；取之前先确认 key 存在（`in` 或 `.get()`），不然 KeyError
5. **写 CSV**：手动拼 `"city,temperature,weathercode\n"` 字符串 + `open(..., "w", encoding="utf-8")` 即可，今天不用 csv 模块（第 3 周再上正规工具）
6. **坏数据处理（复习 Day 4/5）**：逐行 try/except，坏行打印原因跳过，绝不整脚本崩溃
7. **单点失败隔离**：每个城市一个 try/except，一个城市失败不影响其他城市
