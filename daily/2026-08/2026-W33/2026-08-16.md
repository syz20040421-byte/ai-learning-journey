## 今日知识点预习 (10 min · 只看两条，其余不动)

### 1. pathlib 的正解：同目录文件直接拼，别用 `..`

- **是什么**：`Path(__file__).parent` 就是脚本自己所在目录；同目录的文件直接 `BASE_DIR / "cities.csv"`。
- **为什么今天用**：你昨天的写法 `(BASE_DIR / "../../2026-08-10/cities.csv").resolve()` 解析到了**不存在的目录**（教练已实测 `exists() == False`）——`..` 跳多了。归档后 `cities.csv` 和 `06_integration.py` **就在同一个目录**（`submissions/2026-08/2026-W33/2026-08-10/` 下，`ls` 可见），根本不需要跳。
- **怎么用**：
  ```python
  BASE_DIR = Path(__file__).parent          # submissions/.../2026-08-10/
  read_list = load_cities(str(BASE_DIR / "cities.csv"))   # 同目录，直接拼
  ```
- **坑**：`..` 在代码里是坏味道——目录结构一动就碎，和硬编码路径是同一个病。以后一律「脚本在哪，数据就拼哪」。

### 2. Git 冲突解决流程（复习三问 Q3，今天实操）

- **是什么**：merge 冲突时 git 在文件里插入三行标记：`<<<<<<< HEAD`（你的）到 `=======`，`=======` 到 `>>>>>>> 分支名`（对方的）。
- **怎么用**：手动把冲突段改成最终想要的版本 → **删掉所有标记行** → `git add` → `git commit`。
- **坑**：`git merge` 冲突后处于「合并中」状态，不解决完不能切分支；解决完必须 commit，merge 才算完成。
