## 今日知识点预习 (15-20 min · 详读)

四段式：是什么 / 为什么今天用 / 怎么用 / 坑。

### 1. 函数是一等公民：函数可以当参数、当返回值

- **是什么**：Python 里函数也是对象，可以像变量一样传来传去：`f = print` 之后 `f("hi")` 就打印 hi。
- **为什么今天用**：装饰器（第 2 条）的全部魔法都建立在「函数能当参数、能当返回值」上。不理解这一条，装饰器就是天书。
- **怎么用**：
  ```python
  def greet(name):
      return f"你好，{name}"
  fn = greet        # 不调用，只是把函数对象存起来
  print(fn("小明"))  # 你好，小明
  ```
- **坑**：`greet` 和 `greet()` 是两回事——前者是函数对象，后者是调用结果。写装饰器时到处是这种区分，漏了括号就报 `TypeError: 'NoneType' object is not callable`。

### 2. 装饰器：给函数加「包装」

- **是什么**：`@timer` 写在函数定义上面，等价于 `func = timer(func)`——把原函数传进 `timer`，用返回的新函数替换掉原函数名。
- **为什么今天用**：面试必问「装饰器是什么/写过吗」，第 4 周调 LLM API 时你会需要自动重试、计时、日志——全是装饰器场景。今天先写最简单的计时器。
- **怎么用**：
  ```python
  import time
  def timer(func):
      def wrapper(*args, **kwargs):
          t0 = time.time()
          result = func(*args, **kwargs)   # 调用原函数
          print(f"{func.__name__} 耗时 {time.time()-t0:.4f}s")
          return result                     # 把原函数的结果原样返回
      return wrapper                        # 返回包装函数

  @timer
  def slow_add(a, b):
      time.sleep(0.1)
      return a + b

  print(slow_add(1, 2))   # slow_add 耗时 0.1000s / 3
  ```
- **坑**：① `wrapper` 必须 `return result`——漏了原函数返回值就变成 None；② `wrapper(*args, **kwargs)` 必须接收并透传所有参数——写死参数个数，原函数换个签名就崩；③ 别忘 `import time`。

### 3. 迭代器协议：for 循环的底层真相

- **是什么**：任何对象只要实现了 `__iter__`（返回迭代器）和 `__next__`（返回下一个值，没有则抛 `StopIteration`），就能被 for 遍历。`for x in it` 等价于 `it = iter(obj); while True: x = next(it)`。
- **为什么今天用**：你昨天写的生成器函数（yield）本质上就是迭代器——`for` 能遍历生成器、list、dict、文件，全是因为它们都实现了这套协议。看懂协议，昨天「生成器只能走一遍」的坑就有了理论解释。
- **怎么用**（用 `next()` 手动驱动，亲眼看到 StopIteration）：
  ```python
  gen = (x * x for x in range(3))
  print(next(gen))   # 0
  print(next(gen))   # 1
  print(next(gen))   # 4
  print(next(gen))   # StopIteration（for 循环就是靠捕获这个异常来结束的）
  ```
- **坑**：`next()` 越过最后一个值会抛 `StopIteration`，手动调用时要做好心理准备（for 循环自动处理了）；迭代器是「一次性」的，`list(gen)` 消费完就空了。

### 4. 装饰器带参数（理解即可，今天不写）

- **是什么**：`@timer(level=2)` 这种带括号的装饰器，是「装饰器工厂」——先返回一个装饰器，再装饰。今天只要知道存在这层，能看懂报错不慌即可。
- **为什么今天用**：面试会问「装饰器怎么带参数」，今天知道答案方向（再加一层函数）就行，不用写出来。
- **怎么用**：看廖雪峰教程对应小节，能复述「三层嵌套」即可。
- **坑**：别在理解基础装饰器之前就纠结带参数版——那是「会走之前学跑」。

Mia tried again. The fourth bread was a little better. The fifth was almost right. On the sixth Saturday, she carried a golden loaf to her grandmother. The smell filled the kitchen.

"Now," her grandmother said, "you are ready to learn the next thing."

"Your cousin's recipe. There is always a next thing. Baking is not one lesson. It is a hundred small lessons, one after another. The people who give up after two tries never reach lesson number three. The people who keep going — they end up with bread."
